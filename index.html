Unit Converter

Choose the units and decimal places, then type a value on either side. The other side updates instantly.

Conversion reference

Exact definitions: 1 in = 25.4 mm, 1 lbf = 4.4482216152605 N, 1 kgf = 9.80665 N. Other factors are derived from these. Calculations use full precision; only the displayed result is rounded to the decimal places you choose, so converting a rounded result back may differ slightly from the original value.

About this tool

This is a conversion aid only. It does not connect to or change the testing machine’s software, calibration, test method, or reported test data. Always confirm units against the applicable test standard and machine procedure.

All calculations run in your browser. No values are sent or stored.
